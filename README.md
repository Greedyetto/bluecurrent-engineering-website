# BlueCurrent Engineering

Static website for **BlueCurrent Engineering**.

**Electrical • Automation • Drives • Dredging • Offshore**

Independent electrical, automation and drives engineering consultancy for the dredging, marine and offshore industries.

## Structure

- `index.html` — website content
- `styles.css` — responsive styling
- `script.js` — minimal browser behaviour
- `CNAME` — planned custom domain for GitHub Pages

## Deployment

The site is intended for GitHub Pages with the custom domain:

`bluecurrent-engineering.com`

The `.nl` domain can redirect to the `.com` domain later from TransIP.

## Before public launch

- Confirm that `Edwin.Profijt@bluecurrent-engineering.com` is working.
- Enable GitHub Pages from the `main` branch, root directory.
- Point the DNS records at GitHub Pages.
- Enable HTTPS in GitHub Pages after DNS validation.
- Add legal/privacy pages only if required by future site features such as analytics or contact forms.
